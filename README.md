# quotes_viewer

Программа для построения графиков таблично заданных функций котировок акций:

- **Задача 1** — интерполяция методом **кубических сплайнов**;
- **Задача 2** — аппроксимация **методом наименьших квадратов** (полином
  заданной степени) с продлением графика на `M` дней вперёд (прогноз курса).

Реализована на **C++20** с графическим интерфейсом на **Qt6 Widgets**,
архитектура **MVC**, сборка — **CMake** через Makefile-обёртку.

## Требования

| Компонент | Версия          |
|-----------|-----------------|
| Компилятор | GCC ≥ 11 / Clang ≥ 13 (стандарт C++20) |
| CMake     | ≥ 3.16          |
| Qt6       | ≥ 6.2, компонент `Widgets` |
| GNU Make  | любая современная |

## Сборка и установка

Стандартный набор целей GNU-программы обеспечивается Makefile-обёрткой над
CMake: `all`, `install`, `uninstall`, `clean`, `dvi`, `dist`.

```bash
make all                # сборка (создаёт каталог build/ и собирает проект)
make install            # установка в /usr/local
make install PREFIX=$HOME/.local   # установка в произвольный каталог
make uninstall          # удаление установленных файлов
make clean              # удаление каталога build/
make dvi                # документация
make dist               # архив исходников s21_quotes_viewer-1.0.0.tar.gz
```

## Запуск

```bash
./build/s21_quotes_viewer
```

После установки запуск выполняется командой `<PREFIX>/bin/s21_quotes_viewer`.

## Интерфейс

Верхняя панель общая для обеих задач: кнопка **«Загрузить CSV…»**, имя файла,
число записей и период данных. **При загрузке нового файла оба поля отрисовки
очищаются** (требование задачи), а минимум счётчика точек становится равным
числу записей файла.

### Вкладка «Задача 1. Интерполяция сплайном»

- счётчик точек `n` (не меньше записей файла); точки равномерно распределяются
  между начальной и конечной датами данных, соседние соединяются прямой;
- кнопка **«Построить сплайн»** — график сплайна добавляется на поле;
- кнопка **«Очистить поле»** — единственный способ (кроме загрузки нового
  файла) убрать графики;
- до **5 графиков одновременно**, все разного цвета; при 5 графиках кнопки
  отрисовки блокируются до очистки поля;
- легенда: цвет графика и имя файла-источника;
- поля даты и времени + кнопка **«Вычислить»** — значение сплайна в заданный
  момент времени (дата вне диапазона данных ограничивается краями).

### Вкладка «Задача 2. Аппроксимация (МНК)»

- счётчик точек, поле **степени полинома** (0…15) и поле **M** — на сколько
  дней вперёд продлевается график;
- график строится на расширенном диапазоне `[начало; конец + M]`; график
  всегда покрывает больший промежуток времени, чем исходные данные;
- **исходные точки файла явно отмечены маркерами** тёмного цвета; радиус
  маркера больше толщины кривой, цвет не совпадает с цветами графиков;
- если новый график строится с **M, отличным от уже отрисованных**, поле
  предварительно очищается; до 5 графиков с одним значением M;
- легенда: цвет, имя файла, степень полинома и M;
- по дате и времени выводится значение аппроксимирующего полинома текущей
  степени (в том числе за пределами исходных данных — экстраполяция).

## Формат входных данных

CSV-файл с двумя столбцами и заголовком (регистр заголовка не важен):

```csv
Date,Close
2021-03-22,123.389999
2021-03-23,122.540001
2021-03-24,120.089996
```

Требования: даты в формате `YYYY-MM-DD`, значения — числа; записи
сортируются по дате автоматически; дубликаты дат и некорректные строки
приводят к ошибке загрузки с указанием номера строки; требуется не менее
двух записей. Примеры в `data/` — синтетические котировки AAPL, MSFT и SBER
за 2021 год, сгенерированы скриптом случайного блуждания.

## Архитектура MVC

```
src/
├── model/          Модель — чистый C++20, ни одного включения Qt
│   ├── s21_quote.h            типы: Quote, GraphPoint, Result<T>, chrono-утилиты
│   ├── s21_csv_loader.*       загрузчик и валидатор CSV
│   ├── s21_cubic_spline.*     кубический сплайн (метод прогонки)
│   ├── s21_least_squares.*    МНК (нормальные уравнения, метод Гаусса)
│   └── s21_quotes_model.*     фасад модели: данные + оба метода
├── controller/     Контроллер — знает модель, не знает Qt
│   ├── s21_controller.*       тонкий контроллер: пересборка типов + пересылка
│   └── s21_selftest.*         консольный самотест модели и контроллера
├── view/           Представление — Qt6 Widgets, не включает заголовков модели
│   ├── s21_plot_widget.*      отрисовка на QPainter: оси, сетка, ломаные, маркеры
│   └── s21_main_window.*      главное окно, две вкладки, легенды, кнопки
├── s21_main.cpp                точка входа GUI (+ --demo, --selftest)
└── s21_main_selftest.cpp       консольная точка входа самотеста
```

- **Модель** не знает о существовании интерфейса: ошибки возвращаются через
  `Result<T>` (аналог `std::expected`), без исключений.
- **Представление** общается с моделью только через контроллер и оперирует
  собственными типами (`ControllerPoint`, `ControllerDateTime`, `LoadInfo`,
  `GraphResult`, `ValueResult`), поэтому ни один заголовок Qt не попадает в
  модель и ни один заголовок модели — в представление.
- **Контроллер** тонкий: только преобразование типов и пересылка вызовов,
  без бизнес-логики.
- В сборке это закреплено физически: статическая библиотека `s21_model`
  собирается без путей к Qt, а `s21_controller` линкуется с ней и тоже не
  зависит от Qt.

## Методы вычислений

### Кубический сплайн

На каждом отрезке `[x_i; x_{i+1}]` сплайн — полином третьей степени
`S_i(x) = a + b·dx + c·dx² + d·dx³`, `dx = x − x_i`. Неизвестные вторые
производные в узлах находятся из системы непрерывности первой производной;
граничные условия естественные: `S''(x_0) = S''(x_n) = 0`. Трёхдиагональная
система решается **методом прогонки** (алгоритм Томаса) за O(n). Сплайн точно
проходит через все узлы данных (проверяется самотестом).

### Метод наименьших квадратов

Полином степени `k` подбирается минимизацией суммы квадратов отклонений:
нормальные уравнения Грама `(k+1)-го порядка` решаются **методом Гаусса с
частичным выбором ведущего элемента**. Для численной устойчивости абсциссы
(дни с эпохи, ~19000) предварительно нормируются в отрезок `[-1; 1]`, поэтому
даже высокая степень не приводит к переполнению при возведении в степень.
Экстраполяция за пределы выборки (прогноз на M дней) вычисляется по схеме
Горнера.

## Самотест

`--selftest` проверяет: загрузку и валидацию CSV; равномерность и число точек
графиков; точное прохождение сплайна через узлы; продление диапазона ровно на
M суток; вычисление значений по дате и времени (включая прогноз); отклонение
некорректных запросов (слишком мало точек, слишком высокая степень, `M = 0`,
несуществующий файл); точность сплайна на `sin(x)` (< 10⁻³) и точность МНК на
`y = x² + 1` (< 10⁻⁶).

## Возможности C++20, использованные в проекте

| Возможность | Где |
|---|---|
| Календарный API `std::chrono` (`year_month_day`, `sys_days`, `days`) | хранение дат, арифметика продления на M дней |
| `std::ranges`: `sort`/`transform`/`for_each`/`upper_bound` с проекциями | загрузчик CSV, сплайн, модель |
| `std::views`: `split`, `iota`, `reverse` | разбор строк дат, равномерная выборка точек, схема Горнера |
| Концепты (`std::invocable<double>`) | шаблон `SampleUniform` в модели |
| Именованные инициализаторы | создание `Quote`, `GraphPoint`, структур контроллера и Qt-графиков |
| `std::string::starts_with` | пропуск строки-заголовка CSV |
| Структурированные привязки | `from_chars`, результаты контроллера |
| `std::from_chars` (в т.ч. для `double`) | парсер чисел без выделений памяти и локали |
| `[[nodiscard]]`, `constexpr` | API модели и виджета |
